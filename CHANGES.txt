Release notes
-------------

Date          Version   Comment
2026/08/24    1.3.0     Fix activities never completing again after a reset. The reset
                        deleted course_modules_completion but left course_modules_viewed
                        behind; completion_info::set_module_viewed() returns early while
                        that row exists, so view-tracked activities (certificates, pages,
                        files, ...) stayed incomplete forever and the course never
                        recompleted. The viewed rows are now archived to the new
                        local_recertify_cmv table and removed, and an upgrade step clears
                        the rows left behind by earlier releases.
                        Add mod_lesson and mod_h5pactivity reset handlers. Their completion
                        rules are evaluated live against the module data, so leaving it in
                        place made the activity count as completed again without the user
                        repeating it.
                        Add an optional "Reset quiz overrides" setting so extra attempts
                        granted in an earlier cycle stop accumulating.
                        Fix local_recertify_qa silently dropping timemodifiedoffline and
                        gradednotificationsenttime when archiving quiz attempts.
                        Make check_recertify::reset_user() load locallib.php itself.
                        Add PHPUnit coverage for the reset paths, including the SCORM
                        schema fix from 1.2.1.
2026/08/10    1.2.1     Fix SCORM reset failing with "Table 'scorm_scoes_track'
                        doesn't exist". That table was removed in Moodle 4.3
                        (MDL-77943); tracking data now lives in scorm_attempt,
                        scorm_element and scorm_scoes_value. Archiving joins the
                        three tables back into the flat local_recertify_sst
                        format and deletion uses core's scorm_delete_tracks().
2026/04/29    1.2.0     Supervisor notification: deduplicate password resets per
                        user per task run so multiple supervisors and multiple
                        courses report the same valid credentials (fixes a race
                        where only the last-generated password actually worked).
                        Replace hardcoded random-...@vds.de email regex with a
                        configurable custom user profile field
                        (local_recertify/noemailprofilefield) for detecting
                        users without a real email address.
2026/04/17    1.1.0     Submission readiness: fix all 63 codechecker errors and
                        42 warnings (variable renames, docblocks, inline comments,
                        commented-out code removal). Replace MySQL-specific
                        UNIX_TIMESTAMP() with portable PHP time() parameter.
                        Fix SQL injection risk by parameterising $roleid.
                        Rename getEmail() to get_email(). Remove print_r() and
                        rename var_dump() to dump() in debuglog. Update README.md
                        for Moodle 4.5. Plugin passes phpcs moodle standard with
                        zero errors and zero warnings.
2026/04/15    1.0.0     Initial release for Moodle 4.5. Based on local_recompletion.
                        Install hook auto-migrates archive tables, course config,
                        plugin settings and the reset log from local_recompletion
                        and local_recompletionextension if either predecessor is
                        present.
